# AstraCode

**Code smarter. Automate everything. Build, test, and ship from your phone. Your IDE. Your AI. Your rules.**

AstraCode is an Android-first coding environment focused on mobile development, cloud AI assistance, automated workflows, and building and verifying software from your phone.

## Project status

AstraCode is under active development. Features, compatibility, and setup instructions may change as the project evolves.
